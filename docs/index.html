Two ways to summarize

A powerful CLI for automation and scripting, plus a Chrome Side Panel for one-click browser summaries.

CLI

Terminal power

Built for automation: extract clean text, summarize with any model, output JSON or Markdown. Works with URLs, PDFs, images, audio/video, YouTube, and podcasts.

Chrome Extension

Side Panel summaries

One-click summaries of the active tab with streaming Markdown. Chat agent, auto-summary on navigation, YouTube slide extraction, all inside a Side Panel.

# Web pages
summarize "https://example.com/article"
# YouTube videos
summarize "https://youtu.be/dQw4w9..."
# PDFs, images, audio, video
summarize "/path/to/report.pdf"
# Podcasts
summarize "https://podcasts.apple.com/..."

Summarize anything with a URL

Web pages, YouTube, podcasts, PDFs, images, audio, video — pass any URL or file path and get a clean summary.

  • Smart extraction: Readability, markitdown, and Firecrawl fallback
  • Transcript-first media: published captions, then Whisper fallback
  • Pipe from stdin: pbpaste | summarize -

Any model, any provider

Use gateway-style IDs to pick any model. Auto mode intelligently selects and falls back between providers.

  • OpenAI, Anthropic, Google, xAI, NVIDIA, Z.AI, OpenRouter
  • CLI backends: Claude Code, Codex, Gemini CLI, Cursor Agent
  • Free preset via OpenRouter --model free
--model auto # intelligent selection + fallback
--model openai/gpt-5-mini
--model anthropic/claude-sonnet-4-5
--model google/gemini-3-flash-preview
--model xai/grok-4-fast-non-reasoning
--model free # OpenRouter free models
--cli claude # use Claude Code as backend

Built for real extraction

Not a wrapper around an API. A full pipeline for clean, reliable summaries.

Smart extraction

Readability for articles, markitdown for complex pages, Firecrawl fallback when sites fight back. HTML, Markdown, and plain text output.

$ summarize "https://..." --extract --format md

YouTube + Podcasts

Prefers published transcripts, falls back to Whisper. Supports Apple Podcasts, Spotify, RSS feeds, and YouTube with slide extraction and OCR.

$ summarize "https://youtu.be/..." --slides --slides-ocr

Streaming output

Real-time Markdown rendering in the terminal with ANSI formatting, progress indicators, token counts, timing, and cost estimates.

$ summarize "https://..." --stream on --metrics detailed

Scriptable JSON output

Machine-readable output with diagnostics, prompt metadata, metrics, and optional summary. Pipe into jq, build automations, or integrate with other tools.

$ summarize "https://..." --json | jq '.summary'

How it works

Three steps. One command.

1

Fetch + Extract

Pull the source, clean HTML, normalize content, or download media for transcription.

2

Transcript if needed

For media inputs, use published transcripts first. Fall back to local Whisper or cloud transcription.

3

Summarize + Stream

Send to your chosen LLM. Stream output in the terminal or Side Panel with metrics and cost tracking.

New in v0.11

YouTube slide extraction

Automatically extract slide screenshots from video presentations with scene detection, optional OCR, and timestamped seek links.

  • Scene detection via ffmpeg with configurable thresholds
  • Optional OCR with tesseract for text-heavy slides
  • Inline thumbnails in supported terminals (kitty, iTerm, Konsole)

Chrome extension setup

Three steps to streaming summaries in the browser.

1

Install the CLI

Via npm or Homebrew. Requires Node 22+.

npm i -g @steipete/summarize
2

Get the extension

Install from the Chrome Web Store and open the Side Panel.

Chrome Web Store →
3

Connect the daemon

Copy the token from the Side Panel and install the background service.

summarize daemon install --token <TOKEN>

The daemon runs locally on 127.0.0.1 with token auth. It auto-starts via launchd (macOS), systemd (Linux), or Scheduled Task (Windows).

Configurable output

Control summary length, output language, streaming, themes, and more. Smart defaults that stay out of the way.

--length short, medium, long, xl, xxl, or character count
--lang Output language (auto matches source)
--theme aurora, ember, moss, or mono
--json Machine-readable output with diagnostics

Configuration file

~/.summarize/config.json
{
  "model": "openai/gpt-5-mini",
  "env": {
    "OPENAI_API_KEY": "sk-..."
  },
  "ui": {
    "theme": "ember"
  },
  "cache": {
    "media": { "ttlDays": 7 }
  }
}

Precedence: CLI flags > env vars > config file > defaults.
